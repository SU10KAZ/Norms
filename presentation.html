💡 Что такое эмбеддинги?

Каждый пункт нормы превращается в вектор из 1024 чисел — «координату смысла». Похожие по содержанию пункты оказываются рядом в этом пространстве, даже если написаны разными словами.

💡 Что такое MCP?

Model Context Protocol — стандарт, который позволяет Claude самостоятельно обращаться к базе данных норм. Вы спрашиваете на обычном языке — Claude сам находит нужный пункт.

🚀 На что способна система

  • 🔍
    Семантический поиск Спрашивайте своими словами — система поймёт смысл, а не только ключевые слова
  • 📌
    Точный пункт Не просто документ, а конкретный пункт и номер таблицы с контекстом
  • 🌐
    Граф зависимостей Видите, какие нормы ссылаются друг на друга — не упустите ни одну связь
  • 🎯
    Фильтры по типам Искать только по СП, только по ГОСТам или по всему сразу
  • 🧩
    Похожие нормы Для каждого документа — 5 ближайших по смыслу, даже если они из другой области
  • 🗺️
    Тематические карты 12 MOC-заметок группируют нормы по темам: бетоны, лифты, пожаротушение...
  • 🤖
    Claude-интеграция AI сам обращается к нормам через MCP — вы просто спрашиваете
  • 📓
    Obsidian vault Всё в Markdown — wiki-ссылки, граф, теги. Работает офлайн, вечно ваше
