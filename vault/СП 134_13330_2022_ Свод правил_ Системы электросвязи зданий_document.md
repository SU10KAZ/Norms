##### 1 Область применения
1.1 Настоящий свод правил устанавливает минимально необходимые требования к проектированию систем электросвязи инженерно-технического обеспечения и распространяется на проектирование вновь строящихся, реконструируемых и подлежащих капитальному ремонту зданий и сооружений (далее - объекты) на территории Российской Федерации.
1.2 Настоящий свод правил не распространяется на частные индивидуальные дома, некапитальные строения и сооружения, высотные здания, транспортные сооружения (метро, мосты, эстакады, тоннели), защитные сооружения гражданской обороны, на объекты повышенного уровня ответственности, отнесенные к особо опасным, технически сложным и уникальным объектам. Для таких объектов оснащение специальными системами связано с технологическими процессами, соответствующими их функциональному назначению [1] - [3].

###### Расчет W_{obs} с учетом "эквивалентной" стены
Вариант расчета W_{obs} с учетом "эквивалентной" стены используется в случае, если есть план здания, но точно не известны толщина препятствий (стен) L, м, и тип материала, из которых изготовлены препятствия (стены) M.
Примечание - В связи с появлением новых материалов, на этапе подготовки исходных данных необходимо получить информацию о величине погонного затухания W_{prop}, дБ/м, для каждого типа материала (типа стены) для выбранного диапазона частот радиосигнала.
Данный вариант расчета следует использовать на этапе предварительного планирования сети внутри помещений, когда требуется получить примерную оценку количества антенн.
При данном варианте расчета на основании плана здания определяют количество препятствий (стен) N на трассе между передатчиком и приемником, а толщину каждой стены L, м, принимают одинаковой, также одинаковым для каждой стены принимают материал M, из которого стена изготовлена и, следовательно, принимают одинаковым для каждой стены и погонное затухание W_{prop}, дБ/м.
В данном варианте затухание радиосигнала, W_{obs}, дБ, обусловленное препятствиями на трассе между передатчиком и приемником, рассчитывают по следующему алгоритму:
- 1) построение профиля препятствий на трассе между передатчиком и приемником и определение длины трассы R, м;
- 2) определение количества препятствий на трассе между передатчиком и приемником N;
- 3) расчет затухания радиосигнала W_{obs}, дБ, обусловленного препятствиями на трассе между передатчиком и приемником, по формуле
W_{obs} = N \cdot L \cdot W_{prop}, (A.3)где N - количество препятствий на трассе между передатчиком и приемником;
L - усредненная ширина препятствия, м, установленная в модели по умолчанию (0,1 - 0,5 м);
W_{prop} - усредненная величина погонного затухания для каждого препятствия, дБ/м, установленная в модели по умолчанию.
Так как при данном варианте расчета величину W_{obs} определяют на основе усредненных и одинаковых для всех препятствий (стен) параметров L, м, и W_{prop}, дБ/м, то это позволяет заменить реальные препятствия (стены) между передатчиком и приемником как бы одной "эквивалентной" стеной. Поэтому этот вариант получил название "Учет эквивалентной стены".
Данный вариант расчета дает неизбежные ошибки, связанные с усреднением параметров толщины L, м, и погонного затухания W_{prop}, дБ/м, реальных препятствий (стен), но позволяет получить результат при наличии минимума исходных данных о конфигурации здания.
###### Расчет W_{obs} с учетом каждой стены
Вариант расчета W_{obs} с учетом каждой стены используется в случае, если есть полноценные законченные строительные чертежи здания, информация из которых достоверна. При этом из чертежей возможно получить информацию о толщине препятствий (стен) L и типе материала, из которого изготовлены препятствия (стены) M.
Данный вариант позволяет получить более точную оценку величины W_{obs} и, следовательно, спланировать сеть внутри помещений и составить спецификацию оборудования более корректно.
